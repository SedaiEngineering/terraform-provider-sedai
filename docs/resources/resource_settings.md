# sedai_resource_settings (Resource)

Manages the top-level settings for a single Sedai resource — the most-specific override in the inheritance chain. Only attributes specified here are tracked for drift; per-resource-type tuning fields (scaling limits, etc.) are preserved untouched.

## Example Usage: aggression mode (Turbo)

`aggression_mode` sets how aggressively Sedai optimizes Kubernetes and ECS workloads: `PROD`, `EXPEDITE` or `TURBO` ("Speed" in the Sedai UI, Kubernetes only). It is not `optimization_mode`. It needs Sedai 1.148 or later and an admin-role API key.

```terraform
# One Kubernetes workload on Turbo. For an ECS resource use PROD or EXPEDITE.
resource "sedai_resource_settings" "checkout_api" {
  resource_id       = "abc123/Deployment/prod-cluster/payments/checkout-api"
  availability_mode = "DATA_PILOT"
  optimization_mode = "DATA_PILOT"
  aggression_mode   = "TURBO"
}
```

## Schema

### Required

- `availability_mode` (String) Availability mode. Valid values: `DATA_PILOT`, `CO_PILOT`, `AUTO`. Per-resource-type validity rules (e.g. buckets cannot be AUTO) apply at apply-time.
- `optimization_mode` (String) Optimization mode. Valid values: `DATA_PILOT`, `CO_PILOT`, `AUTO`. Per-resource-type validity rules apply at apply-time.
- `resource_id` (String) The Sedai resource ID. Often a slash-delimited path like `abc123/Deployment/prod-cluster/payments/payment-api`.

### Optional

- `aggression_mode` (String) How aggressively Sedai optimizes this resource (Kubernetes and ECS resources only). Valid: `PROD`, `EXPEDITE`, `TURBO` (`TURBO` is Kubernetes only, checked against the resource's type at apply time). Not the same as `optimization_mode` (Data Pilot / Co-Pilot / Autopilot). A change is applied as a mode switch, before the other settings are saved: the switch resets the CPU and memory limits and, on ECS, the replica settings to the mode's defaults (a value set in this block is written again after it), and turns autonomous action without traffic on for EXPEDITE and TURBO and off for PROD. Must agree with `is_prod` when both are set (`is_prod = true` only with `PROD`). Needs Sedai 1.148 or later and an admin-role API key. Destroying the resource leaves the mode as it is.
- `sedai_sync_enabled` (Boolean) When true, Sedai auto-syncs this resource with the latest cloud-side configuration. Defaults to false if omitted.

### Read-Only

- `resource_type` (String) Backend-detected resource type (e.g. `KubernetesAppResourceSettingDetail`, `ServerlessFunctionResourceSettingDetail`). Populated from the API response — read-only.
